Ferry 0.1.0 is the first release: a file transfer client for GNOME, written in Rust with GTK 4 and libadwaita. It browses cloud storage and file servers, moves files in both directions, shares links, keeps folders in sync and opens Cryptomator vaults in place.

## New

- **File servers**: SFTP (also through a jump host, with the SSH agent, smartcards and YubiKeys), FTP over TLS and WebDAV, including Nextcloud and ownCloud.
- **Cloud storage**: Google Drive through GNOME Online Accounts, Azure Blob Storage, and every S3-compatible service, with ready-made settings for Amazon S3, Cloudflare R2, Supabase, MinIO, Backblaze B2, Wasabi, DigitalOcean, Hetzner, Scaleway, OVHcloud, Akamai, Exoscale, Storj and Google Cloud Storage.
- **Encryption**: Cryptomator vaults (format 8) on any bucket or server, and SSE-S3, SSE-KMS or SSE-C with your own key for S3 uploads.
- **Transfers**: a queue with priorities, pause, speed limit and parallel parts. Interrupted uploads and downloads continue where they stopped, also after a restart.
- **Tools**: folder sync with a review before anything changes, scheduled and watched backups, mounting a bucket as a folder, share and upload links with QR codes, bucket settings (policy, CORS, lifecycle, versioning, Object Lock, website hosting, CloudFront), a storage analyzer and a compatibility test for any provider.
- **GNOME integration**: credentials in the keyring, AWS CLI profiles with single sign-on and MFA, a search provider for the overview, the background portal, an adaptive layout, and English and Turkish translations.
- **Connections**: imported from rclone, s3cmd, Cyberduck and the AWS CLI. Backups of them are encrypted with a password, age or SSH keys, a YubiKey or a GnuPG key.
- **Command line**: `ferry ls`, `get`, `put`, `cat`, `share` and `rm` work with the saved connections.

## Downloads

| System | File |
| --- | --- |
| Any Linux distribution | `Ferry-0.1.0-linux-x86_64.flatpak` |
| Fedora 43 and later | `Ferry-0.1.0-linux-x86_64.rpm` |
| Debian 13, Ubuntu 25.04 and later, Pardus 25 | `Ferry-0.1.0-linux-amd64.deb` |
| Arch Linux | `Ferry-0.1.0-linux-x86_64.pkg.tar.zst` |

The Flatpak needs the GNOME 50 runtime from Flathub: `flatpak install --user Ferry-0.1.0-linux-x86_64.flatpak` fetches it. The packages are not signed. `SHA256SUMS` lists the checksum of every file.
